# Purpose (OAR 413-330-1100)

## Full text

413-330-1100 Purpose This administrative rule set (413-330-1100 through 413-330-1150) describes the use of short-form personal-services contracts funded by the Focused Opportunities for Children Utilizing Services (FOCUS) budget within the Department’s Treatment Services Program. This rule set also describes how approval authority for these contracts is delegated to the Department’s managers and supervisors.

Statutory/Other Authority: ORS 409.050 & ORS 418.005 Statutes/Other Implemented: ORS 30.260-30.300, ORS 279A.050-279A.155, ORS 409.010, ORS 670.600 & ORS 806.060
